PROGRAM REGULAR FALSI - PYTHON TERMINAL

Cara menjalankan:
1. Pastikan Python 3 sudah terpasang.
2. Buka terminal/CMD di folder ini.
3. Jalankan: python regular_falsi.py
   Jika perintah tersebut tidak bekerja di Windows, coba: py regular_falsi.py
4. Pilih fungsi, masukkan interval [a,b], toleransi, dan maksimum iterasi.

Catatan:
- f(a) dan f(b) harus berlainan tanda, kecuali salah satu batas sudah merupakan akar.
- Fungsi cos(x)-x menggunakan satuan radian.
- Program menampilkan tabel iterasi, perkiraan akar, f(akar), dan status.
